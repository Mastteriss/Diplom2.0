# ADR 0003. Графики — серверный инлайновый SVG

## Контекст

Контракт (`docs/contract.md` §1 и §7.2) требует полностью серверного
рендеринга: в браузере JavaScript не используется, все графики — инлайновый
SVG, никаких внешних шрифтов и скриптов.

## Решение

Все диаграммы строятся в `app/analysis/charts.py` четырьмя функциями:
`pareto_chart`, `trend_chart`, `spc_chart`, `weight_bar`. Каждая возвращает
готовую строку SVG (не файл и не шаблон).

* Графики регистрируются как глобальные функции Jinja2 в
  `app/web/context.py` (`templates.env.globals.update(...)`) и вызываются прямо
  из разметки.
* Вставка выполняется через `|safe`: см. `analysis_pareto.html`
  (`pareto_chart(...)|safe`), `analysis_trends.html` (`trend_chart(...)|safe`),
  `analysis_spc.html` (`spc_chart(...)|safe`), `config_weights.html`
  (`weight_bar(...)|safe`). `|safe` — это шов, через который доверенный SVG
  попадает в HTML без повторного экранирования.
* Весь динамический текст проходит через `_esc()` (`html.escape(..., quote=True)`)
  внутри `charts.py`.
* При пустом входе `_empty()` возвращает ровно
  `<p class="chart-empty">Нет данных для графика</p>`
  (текст — из `config.CHART_EMPTY_TEXT`).
* `_svg_open()` намеренно не добавляет `xmlns`: SVG вставляется в `text/html`,
  а namespace-URI выглядел бы как внешняя ссылка. Идентификаторы уникальны
  внутри вызова (`_uid()` на основе `uuid`, локальный префикс `pareto`/`trend`/
  `spcx`/`spcr`/`weight`).

Проверка отсутствия клиентского кода: в `app/web` нет тегов `<script>`, нет
`javascript:`, нет `@import` и внешних URL шрифтов.

## Последствия

Положительные:

* Страницы полностью рендерятся на сервере; работает без JavaScript.
* Единая палитра из `config.CHART_SERIES`, оси/сетка из `CHART_AXIS_TEXT` и
  `CHART_GRID` — оформление меняется в конфиге.
* Нет внешних ресурсов, страница не зависит от сети/CDN.

Отрицательные:

* Пересечения подписей, адаптивность и интерактивность ограничены тем, что
  заложено в генераторах; сложные визуализации писать вручную трудозатратно.
* SVG приходит в HTML, увеличивая размер страницы.

## Статус

Принято.
